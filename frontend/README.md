# Sweet Shop Frontend

React frontend application for the Sweet Shop Management System.

## Setup

1. Install dependencies:
```bash
npm install
```

2. Start development server:
```bash
npm run dev
```

3. Build for production:
```bash
npm run build
```

## Environment Variables

Create a `.env` file (optional):
```env
VITE_API_URL=http://localhost:3001/api
```

## Testing

```bash
npm test
```
